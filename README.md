# SmartCare Design Pack: how to use with Cursor (free)
1. Install Node.js (nodejs.org, LTS) and Cursor (cursor.com, free plan).
2. Open a terminal and run:  npx create-next-app@latest smartcare --typescript --tailwind --app
3. Unzip this pack and copy these into the new `smartcare` folder: the `designs` folder, the `.cursor` folder (it may be hidden), and BUILD_PLAN.md.
4. Open the `smartcare` folder in Cursor. Open chat, choose Agent mode.
5. Open BUILD_PLAN.md and paste Step 1 into the chat. Wait. Run `npm run dev`, open http://localhost:3000 and check it.
6. Continue with Step 2, 3, ... one at a time.
